# Contributing

This repository is maintained as part of the Captain Cronos project.

Ecosystem-wide engineering policy is maintained in
[`CaptainCronos-02-Engineering-Manual`](https://github.com/CaptainCronos/CaptainCronos-02-Engineering-Manual).
This repository's documentation supplements that policy with Ventoy-specific
layout and operating guidance.

## Standard workflow

1. Review the current repository status.
2. Make focused changes.
3. Test before committing.
4. Use clear commit messages.
