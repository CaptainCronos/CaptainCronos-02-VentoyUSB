# VentoyUSB Scripts

- [`checksum.sh`](checksum.sh) — create `checksums.txt` for files under `ISO/`
  and `Tools/`
- [`update-ventoy.sh`](update-ventoy.sh) — copy the maintained repository layout
  to a mounted Ventoy filesystem while excluding large installer payloads
- [`verify.sh`](verify.sh) — verify the files recorded in `checksums.txt`

Review each script and its usage output before running it against removable
media.
